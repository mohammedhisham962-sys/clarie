# Claire Sterling — Personal Branding & Portfolio Website

A bespoke, responsive personal branding portfolio website designed with an editorial luxury aesthetic.

## Features
- **Editorial Hero Section**: Deep black and charcoal background with subtle ambient foliage shadows, a delicate 1px rounded rectangular hero border, monochrome dramatic professional portrait positioned slightly left of center, oversized high-contrast serif typography, and a minimal oval CTA button.
- **Interactive Navigation & Smooth Scrolling**: Fast, fluid scrolling to sections with active link tracking and a floating quick-nav bar that appears on scroll.
- **Biography & Philosophy**: Editorial layout highlighting strategic design pillars, client lineage (Gucci, Emirates NBD, MG Motors, Museum of the Future), and key impact metrics.
- **Selected Commissions / Portfolio**: Interactive filter tabs (Culture & Spatial, Luxury Fashion, Fintech, Mobility) with full-featured case study modals detailing challenge, approach, and impact.
- **Accolades & Citations**: Monochromatic editorial awards ledger.
- **Direct Consultation Form & Modal**: Full inquiry form with validation, service chips, direct email copy button with toast notification, and live dual-timezone clocks (Dubai & Paris).
- **Responsive Architecture**: Mobile-optimized fluid typography and layout adaptation.

## Running Locally
```bash
python serve.py
```
Open [http://localhost:8088](http://localhost:8088) in any browser.
